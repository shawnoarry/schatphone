## 功能模块（5 项需求全覆盖）
1. **日程管理**：周/月双视图日历；9 类活动（打歌/排练/综艺/MV/见面会/海外公演等）；新增/编辑时自动**时间冲突检测**并提示；「今天要处理」置顶区（逾期标红 + 一键完成）
2. **行程优先级**：P0-回归期 / P1-重要 / P2-普通 三级；待办清单按 逾期→今日→临近→后续 分组、优先级排序，自动生成每日待办
3. **行程同步**：数据存云端数据表，右上角同步状态指示器（已同步/同步中/离线）；分享链接即共享行程，变更实时同步
4. **数据看板**：本月行程数、已确认/待确认数、空闲天数、活动类型分布（内联 SVG 饼图）、忙碌/空闲比例条
5. **备注与附件**：每行程支持备注 + 附件（文件名/网盘链接，支持多个，`|` 分隔）
