## T2 — 慎用/避免

- **文泉驿系列**：GPL 许可，有"感染"争议，商用项目避免。
- **汉仪字体**：仅 18 款可在京东平台内免费使用，其他场景均为收费授权，勿默认使用。
- **系统自带字体**（微软雅黑、苹方等）：随系统授权，**不可提取出来用于网页嵌入、印刷品或跨平台分发**。设计稿标注可用，交付物慎用。
- **任何"找不到授权声明"的字体**：一律视为不可用。

## 场景 × 气质选字矩阵

### 小红书/社交媒体卡片
- **知识干货型**：思源黑体（正文）+ 得意黑/站酷高端黑（标题）— 清晰+有记忆点
- **文艺生活型**：霞鹜文楷（正文）+ 思源宋体 Bold（标题）— 温润书卷气
- **专业商业型**（如留学/教育品牌）：思源黑体旧字形（正文）+ 思源宋体或阿里巴巴普惠体 Bold（标题）

### 产品册/企业宣传物料
- **现代专业**：阿里巴巴普惠体 全套（字重齐全，电商起家排版友好）
- **高端人文**：思源宋体（标题）+ 思源黑体（正文）
- **年轻活力**：MiSans + 得意黑（标题点缀）

### 网页 / UI
- 首选屏幕优化字体：**MiSans / HarmonyOS Sans / 思源黑体**
- Web 嵌入：用「中文网字计划」(chinese-fonts) CDN 或自行子集化；全量中文字体 3-10MB，必须子集化或用 CDN 分片加载
- 系统栈兜底：`"PingFang SC", "Hiragino Sans GB", "Microsoft YaHei", sans-serif`

### 图书/出版物内页（如单词书）
- 正文：**思源宋体**（印刷品质感）或 **思源黑体**（工具书清爽感）
- 标题：思源黑体 Bold
- 英语单词主体：配衬线（Source Serif）或人文无衬线，见 pairing-rules.md
- 行距 1.6-1.8，行长 25-35 字

### 海报/大标题
- 力量型：站酷高端黑、庞门正道标题体、优设标题黑
- 活泼型：得意黑
- 文艺型：思源宋体 Heavy、汇文明朝体
