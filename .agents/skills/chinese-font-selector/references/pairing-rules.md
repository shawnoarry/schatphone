# 中文排版与中英混排规则

## 中英混排配对原则

中文为主（>80% 版面）时，英文/数字字体服从中文字体气质：

| 中文字体 | 英文/数字搭配 | 理由 |
|---|---|---|
| 思源黑体 | Source Sans / Inter / Helvetica Neue | 同为中性人文无衬线，字面率接近 |
| 思源宋体 | Source Serif / Georgia / Cormorant | 衬线气质一致，衬线风格匹配 |
| 霞鹜文楷 | Lora / Crimson Text | 温润人文衬线，不抢楷体的戏 |
| 阿里巴巴普惠体 | Inter / Roboto | 现代中性 |
| MiSans | Inter / SF Pro | 屏幕优化同族气质 |
| 得意黑 | 字母也用得意黑自带拉丁，或配 DM Sans | 保持活泼感 |

**规则**：中英文混排时英文用 `font-family` 前置声明（英文在前，中文在后），保证英文用西文字体渲染、中文回落到中文字体：
```css
font-family: "Inter", "Source Han Sans SC", "思源黑体", sans-serif;
```

## 中文字号阶梯（印刷/物料通用）

| 层级 | 正文场景 | 小红书卡片 |
|---|---|---|
| 大标题 | 正文 2.5-3.5 倍 | 60-90pt |
| 小标题 | 正文 1.3-1.6 倍 | 36-48pt |
| 正文 | 基准（印刷 9-10.5pt / 屏幕 14-16px） | 24-32pt |
| 注释 | 正文 0.8 倍 | 18-20pt |

## 行距与行长

- 正文行距：**1.5-1.8 倍**（中文比西文需要更大行距）
- 标题行距：1.2-1.3 倍
- 行长：印刷品每行 **25-35 字**；屏幕每行 30-40 字；小红书卡片每行不超过 15 字
- 段间距 ≥ 0.5 行高

## 字距

- 中文正文默认字距（0），不要加 letter-spacing
- 中文标题可微加字距（0.02-0.05em）增加呼吸感
- 中英之间、中文与数字之间加 1/4 全角空格（或依赖 CSS `text-spacing`/排版引擎自动处理）

## 标点规范

- 中文内容用全角标点：，。；：？！""''（）
- 避头尾：标点不能出现在行首（。，！？）或行尾（""《》）
- 数字与百分号、单位之间不折行
- 省略号用 ……（两个），不是 ...

## 常见翻车点

1. **用"系统自带"字体交付印刷** → 微软雅黑/苹方无印刷授权，换成思源黑体
2. **中英混排不声明英文字体** → 英文被中文字体里的拉丁字形渲染，丑且不专业
3. **中文加 italic** → 中文没有斜体，浏览器合成斜体 = 低级错误，强调用字重或颜色
4. **全量加载中文字体上网页** → 3-10MB 卡死首屏，必须子集化或用 CDN 分片
5. **行距太小** → 中文方块字密度高，行距 <1.4 即显拥挤
